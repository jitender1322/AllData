1Why are Tensors preferred over NumPy arrays in Deep Learning?
Tensors are preferred in deep learning because they are highly optimized for mathematical computations and support GPU/TPU acceleration. They also support automatic differentiation, which is very important while training neural networks. Deep learning frameworks like TensorFlow and PyTorch use tensors internally because tensors can efficiently handle multi-dimensional data and large matrix operations.
Example:
A grayscale image can be represented as a 2D tensor while a colored image can be represented as a 3D tensor.
Shape of RGB Image = (Height, Width, Channels) Example = (224, 224, 3)
2How do you handle character encoding issues when reading CSV files?
Sometimes CSV files contain special characters and when Pandas tries to read them, it may throw UnicodeDecodeError. To solve this issue, we specify the correct encoding while reading the file. Common encodings are UTF-8, latin1, and cp1252.
Example:
import pandas as pd # Reading CSV with encoding df = pd.read_csv('data.csv', encoding='latin1')
20What is the primary goal of EDA?
The main goal of Exploratory Data Analysis (EDA) is to understand the dataset deeply before building machine learning models. EDA helps us identify: - Missing values - Outliers - Correlations - Distribution patterns - Data imbalance - Trends and relationships EDA mainly uses statistical summaries and visualizations.
Example:
If we are analyzing house price data, EDA helps us understand which features affect house prices the most.
25What information does a Histogram give you that a Boxplot doesn’t?
A Histogram shows the full distribution of data including: - Shape of distribution - Frequency of values - Skewness - Multiple peaks A Boxplot mainly summarizes the data using quartiles and highlights outliers.
Example:
Histogram can show whether the data is normally distributed or bimodal, while boxplot cannot show detailed distribution shape.
27How do you identify a Normal Distribution visually?
A normal distribution can be identified visually using histograms or KDE plots. The graph usually looks like a symmetric bell-shaped curve where: - Mean ≈ Median ≈ Mode - Data is equally distributed around the center
28What is a Correlation Heatmap?
A Correlation Heatmap visually represents the correlation values between numerical variables. Correlation values range from: - +1 → Strong positive correlation - -1 → Strong negative correlation - 0 → No correlation Correlation does not imply causation. Two variables may be correlated without one causing the other.
33What is a Violin Plot?
A Violin Plot combines the features of a boxplot and KDE plot. It shows: - Median - Quartiles - Density distribution - Shape of the data It is more informative than a boxplot because it displays distribution density.
43How do you visualize time-series data trends?
Time-series trends are usually visualized using line charts. In line charts: - X-axis represents time - Y-axis represents values Line charts help identify: - Trends - Seasonality - Sudden spikes - Cyclic patterns
